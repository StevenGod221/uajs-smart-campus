# Backend — UAJS Smart Campus

El backend utiliza una arquitectura basada en microservicios.

## Microservicios

- usuarios-service
- solicitudes-service
- reservas-service
- recursos-service
- eventos-service
- notificaciones-service

## API Gateway

El API Gateway funciona como punto de entrada para las solicitudes provenientes del frontend.

## Comunicación

Los servicios utilizan APIs REST y comunicación HTTP/HTTPS con JSON.
