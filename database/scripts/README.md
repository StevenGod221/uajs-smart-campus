# Base de datos

Esta carpeta contiene los scripts y recursos relacionados con la persistencia de UAJS Smart Campus.

## Gestor

MySQL.

## Componentes principales

- Usuarios
- Roles
- Servicios
- Solicitudes
- Reservas
- Recursos
- Eventos
- Notificaciones

Los scripts de creación y configuración de la base de datos estarán dentro de `scripts/`.
