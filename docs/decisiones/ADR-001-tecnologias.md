# ADR-001 — Selección de tecnologías

## Contexto

El proyecto UAJS Smart Campus requiere frontend web, APIs REST, arquitectura distribuida, microservicios y persistencia.

## Frontend

Se utilizará React junto con HTML5, CSS3 y JavaScript.

## Backend

Para la implementación de microservicios se utilizará Java y Spring, debido a que la actividad integrativa especifica esta tecnología para los microservicios.

## Base de datos

Se utilizará un gestor relacional. MySQL es la opción recomendada por el documento.

## APIs

Los microservicios expondrán APIs REST utilizando HTTP/HTTPS y JSON.

## Búsqueda

La actividad integrativa contempla el uso de Elasticsearch como motor de búsqueda.

## Control de versiones

Se utilizará Git y GitHub.

## Estado

Aceptada.
