# Requerimientos no funcionales

## RNF01 — Arquitectura distribuida

La solución debe utilizar una arquitectura basada en microservicios.

## RNF02 — APIs

Los microservicios deben exponer APIs REST.

## RNF03 — Comunicación

La comunicación debe utilizar HTTP/HTTPS y JSON.

## RNF04 — Persistencia

La información debe almacenarse en una base de datos relacional.

## RNF05 — Independencia

Cada microservicio debe mantener su propia lógica de negocio.

## RNF06 — Escalabilidad

La arquitectura debe permitir escalar componentes independientemente.

## RNF07 — Disponibilidad

Los componentes deben estar organizados de manera que permitan demostrar principios de disponibilidad.

## RNF08 — Seguridad

El sistema debe implementar autenticación y autorización.

## RNF09 — Mantenibilidad

El código debe estar organizado por responsabilidades.

## RNF10 — Control de versiones

El código debe gestionarse mediante Git y GitHub.

## RNF11 — Documentación

Las APIs y decisiones técnicas deben documentarse.

## RNF12 — Datos

Durante el desarrollo deben utilizarse datos de prueba.
