# Requerimientos funcionales

## RF01 — Autenticación

El sistema debe permitir que los usuarios accedan mediante autenticación.

## RF02 — Gestión de usuarios

El sistema debe permitir gestionar usuarios y sus roles.

## RF03 — Consulta de servicios

El usuario debe poder consultar los servicios universitarios disponibles.

## RF04 — Solicitudes

El usuario debe poder registrar solicitudes.

## RF05 — Consulta de solicitudes

El usuario debe poder consultar sus solicitudes.

## RF06 — Seguimiento

El usuario debe poder consultar la evolución del estado de una solicitud.

## RF07 — Reservas

El usuario debe poder consultar recursos disponibles y solicitar reservas.

## RF08 — Recursos

El sistema debe gestionar los recursos universitarios disponibles.

## RF09 — Eventos

El sistema debe permitir consultar eventos y actividades.

## RF10 — Notificaciones

El sistema debe mostrar notificaciones generadas por la plataforma.

## RF11 — Perfil

El usuario debe poder consultar su información básica.

## RF12 — Dashboard

El sistema debe mostrar indicadores relacionados con solicitudes, reservas, notificaciones, eventos y servicios.

## RF13 — PQRS

El sistema debe proporcionar un módulo para la gestión de PQRS.

## RF14 — Búsqueda

El usuario debe poder buscar servicios o información disponible.

## RF15 — Comunicación entre servicios

Los componentes del sistema deben comunicarse mediante APIs REST.
