# Wireframes – UAJS Smart Campus

## 1. Objetivo

Los wireframes representan la estructura inicial de las principales interfaces del sistema

## 2. Pantallas

### Landing

Permite presentar el sistema y acceder al inicio de sesión

### Login

Permite al usuario ingresar sus credenciales

### Dashboard

Presenta un resumen de las funcionalidades principales

### Solicitudes

Permite:

- Consultar solicitudes
- Crear solicitudes
- Visualizar información
- Gestionar estados

### Reservas

Permite:

- Consultar reservas
- Crear reservas
- Consultar detalles
- Cambiar estados
- Eliminar reservas

### Recursos

Permite:

- Consultar recursos
- Crear recursos
- Editar recursos
- Eliminar recursos
- Cambiar estados

### Eventos

Permite consultar y gestionar los eventos disponibles

### Notificaciones

Permite consultar las notificaciones del usuario

### Perfil

Permite consultar la información del usuario

### PQRS

Permite presentar solicitudes, preguntas, quejas, reclamos o sugerencias

## 3. Navegación

La navegación se realiza mediante React Router

Rutas principales:

- `/`
- `/login`
- `/dashboard`
- `/dashboard/servicios`
- `/dashboard/recursos`
- `/dashboard/reservas`
- `/dashboard/solicitudes`
- `/dashboard/eventos`
- `/dashboard/notificaciones`
- `/dashboard/perfil`
- `/dashboard/pqrs`
